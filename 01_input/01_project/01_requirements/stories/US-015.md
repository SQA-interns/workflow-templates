# US-015 Filter the Contact list

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want to filter the Contact list by Tags, Attributes, company and country, so that I get exactly the Contacts of one category, for example all `udelezenec2025` without `neObvescaj`.

## Purpose

Tags serve as categories (Q-09 F4) and the customer wants filtering (Q-09 F8); the filtered list is what Export takes (Q-16).

## Definitions

| Term | Meaning |
|---|---|
| Active filters | The filters currently applied, shown as removable chips above the list. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-015-01 | When the User filters by "has Tags" with one or more Tags, the system shall show only Contacts that have all of those Tags. [ASSUMPTION] "all" rather than "any". | Q-09 |
| R-015-02 | When the User filters by "without Tags" with one or more Tags, the system shall show only Contacts that have none of those Tags. [ASSUMPTION] exclusion not stated; needed for Tags like `neObvescaj`. | Q-09 |
| R-015-03 | When the User filters by an Attribute key and value, the system shall show only Contacts with that key whose value equals the given value case-insensitively; with a key and no value, Contacts that have that key. [ASSUMPTION] matching not given. | Q-27, BR-11 |
| R-015-04 | When the User filters by company or by country, the system shall show only Contacts whose company equals the given text case-insensitively, or whose country is the given country. [ASSUMPTION] these Field filters not given. | Q-09 |
| R-015-05 | The system shall combine all Active filters and the search (R-014-04) with AND. | Q-09 |
| R-015-06 | When the User removes a filter chip or chooses "Clear filters", the system shall remove that filter, or all, and show the list again. | Q-04 |
| R-015-07 | The system shall show the count of the filtered list and keep the chosen sort (R-014-03). | Q-04 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-015-01 | "has Tags" with two Tags | Only Contacts with both | R-015-01 |
| EX-015-02 | Same Tag in "has" and "without" | Empty list, "No Contacts match." | R-015-05 |
| EX-015-03 | Attribute key with no value given | Every Contact that has the key | R-015-03 |
| EX-015-04 | Tag filter via the API with a Tag id of another Group | HTTP 404 | BR-02 |
| EX-015-05 | Filtered list matches a Contact in the recycle bin | Not shown | BR-09 |

## Out of scope

OR combinations between filters; saving filters; filtering on other Fields, on dates or on notes.
