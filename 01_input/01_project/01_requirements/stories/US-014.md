# US-014 Browse and search the Contact list

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want a clear Contact list of the current Group that I can sort and search, so that I find a Contact in seconds.

## Purpose

A friendly overview and search are the product's competitive advantage over CRM systems (Q-04, Q-09 F8).

## Definitions

| Term | Meaning |
|---|---|
| Page | 50 Contacts of the list. [ASSUMPTION] page size not given. |
| Normalised text | Text in lower case with diacritics removed (`č` → `c`, `š` → `s`, `ž` → `z`, `ć` → `c`, `đ` → `d`). |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-014-01 | The system shall show the active Contacts of the current Group one Page at a time, with the columns name (first and last name), company, e-mail, phone and Tags, and the total count ("128 Contacts"). [ASSUMPTION] columns not given. | Q-04, BR-09 |
| R-014-02 | The system shall sort the list by last name, then first name, then company, A–Z in Slovenian collation, unless the User chooses another sort. [ASSUMPTION] default sort not given. | — |
| R-014-03 | When the User chooses to sort by name, company, e-mail or last changed, ascending or descending, the system shall sort the whole list that way. | Q-04 |
| R-014-04 | When the User enters search text, the system shall show only Contacts where the normalised text of first name, last name, e-mail, phone, company or city contains the normalised search text. [ASSUMPTION] searched Fields and diacritic-insensitivity not given. | Q-09 |
| R-014-05 | If the search matches no Contact, then the system shall show "No Contacts match." with "Clear search". | Q-04 |
| R-014-06 | When the User opens a row, the system shall show the Contact's details with its Attributes, Tags and a link to its History. | Q-04 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-014-01 | "Konferenca 2025" has active Contacts "Janez Novak", "Maja Zupan", "Žiga Čuk" and "Ana Bizjak" (in recycle bin) | Petra opens the Contact list | it shows "3 Contacts" in the order Čuk, Novak, Zupan; "Ana Bizjak" is not shown | R-014-01, R-014-02, BR-09 |
| AC-014-02 | as AC-014-01 | Petra searches "cuk" | only "Žiga Čuk" is shown | R-014-04 |
| AC-014-03 | "Janez Novak" has company "Podjetje d.o.o." | Petra searches "PODJETJE" | "Janez Novak" is shown | R-014-04 |
| AC-014-04 | as AC-014-01 | Petra searches "xyz" | "No Contacts match." with "Clear search" | R-014-05 |
| AC-014-05 | 120 active Contacts | Petra opens page 3 | Contacts 101–120 are shown and "120 Contacts" | R-014-01 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-014-01 | 50 Contacts / 51 Contacts | 1 Page / 2 Pages | R-014-01 |
| EX-014-02 | Empty Group | "No Contacts yet." with "Add a Contact" | R-014-01 |
| EX-014-03 | Search text "  novak " | Trimmed; "Janez Novak" found | R-014-04 |
| EX-014-04 | Contact with only a company | Sorted by company in the name position | R-014-02 |
| EX-014-05 | Search text with `%` or `_` | Matched literally, not as a wildcard | R-014-04 |
| EX-014-06 | Page number beyond the last Page via the API | Empty page, correct total | R-014-01 |
| EX-014-07 | A Contact of another Group matching the search | Never shown | BR-01 |

## Out of scope

Filters by Tag, Attribute or Field (US-015); saved searches; choosing columns; searching Attribute values and notes.
