# US-013 Permanently delete a Contact

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner, I want to permanently delete a Contact from the recycle bin, including all its Versions, so that a person's data is really erased when they ask for it.

## Purpose

The right to erasure requires that a Contact's data, including its old Versions, can be removed (Q-32, OPEN — needs customer); only the Owner may do it (Q-22).

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-013-01 | When the Owner confirms "Delete permanently. This cannot be undone." for a Contact in the recycle bin, the system shall delete the Contact, all its Versions, Attributes and Tag assignments. | Q-22, Q-32 (OPEN — needs customer) |
| R-013-02 | When a Contact is permanently deleted, the system shall write an Audit entry "contact <id> permanently deleted by <user> at <time>" that holds no other data of the Contact. | Q-32 |
| R-013-03 | If a permanent delete is requested for an active Contact, then the system shall reject it with HTTP 409 "Move the Contact to the recycle bin first." and change nothing. [ASSUMPTION] not given; keeps every deletion two-step. | — |
| R-013-04 | If another Contact is merged into the Contact to be permanently deleted, then the system shall reject it with "Undo the Merge first." and change nothing. [ASSUMPTION] applies once US-018 exists. | — |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-013-01 | "Janez Novak" with 4 Versions is in the recycle bin | Ana confirms "Delete permanently" | it is not in the recycle bin; `GET` on the Contact and on its Versions returns HTTP 404; the Audit log has one entry with the Contact id, Ana and the time, and no name or e-mail | R-013-01, R-013-02 |
| AC-013-02 | as AC-013-01 | Marko (Editor) requests it through the API | HTTP 403; the Contact stays in the recycle bin | BR-04 |
| AC-013-03 | "Maja Zupan" is active | Ana requests a permanent delete through the API | HTTP 409 "Move the Contact to the recycle bin first."; unchanged | R-013-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-013-01 | Ana cancels the confirmation | Nothing changes | R-013-01, BR-07 |
| EX-013-02 | Tag used only by the deleted Contact | The Tag is no longer suggested (R-009-02) | R-013-01 |
| EX-013-03 | A merged Contact points to the Contact being deleted | "Undo the Merge first."; unchanged | R-013-04 |
| EX-013-04 | Contact id that does not exist | HTTP 404 | R-013-01 |

## Out of scope

Permanently deleting an active Contact in one step; deleting the Audit entry; deleting a whole Group permanently before its removal date.
