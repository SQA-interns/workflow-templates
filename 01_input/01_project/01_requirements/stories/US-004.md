# US-004 Invite a Member

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner, I want to invite a person by e-mail as an Editor or a Viewer through a link I send them myself, so that my colleagues can work with the Group's Contacts.

## Purpose

A Group is shared by the people of one project (Q-07). The product sends no e-mail (Q-30), so the Owner copies the Invitation link and sends it (Q-35).

## Definitions

| Term | Meaning |
|---|---|
| Invitation link | `<product URL>/invitations/<token>`; the token is shown only once, when the Invitation is created. |
| Open Invitation | An Invitation in state `open` whose `expiresAt` has not passed. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-004-01 | When the Owner creates an Invitation with an e-mail address and the Role Editor or Viewer, the system shall create an open Invitation valid for 7 days and show its Invitation link once, with a "Copy link" action. | Q-35 (OPEN — needs customer) |
| R-004-02 | If the e-mail address belongs to a User who is already a Member of the Group, then the system shall reject the Invitation with "This person is already a Member." and create nothing. | Q-35 |
| R-004-03 | When the Owner creates an Invitation for an e-mail that already has an open Invitation in the Group, the system shall revoke the earlier Invitation. [ASSUMPTION] not given; keeps one valid link per person. | — |
| R-004-04 | When a signed-in User whose e-mail equals the Invitation's e-mail opens an open Invitation's link and accepts it, the system shall make the User a Member with the Invitation's Role and set the Invitation to `accepted`. | Q-35 |
| R-004-05 | If the signed-in User's e-mail differs from the Invitation's e-mail, then the system shall show "This Invitation is for another e-mail address." and create no Membership. [ASSUMPTION] binding to the e-mail not stated; prevents a forwarded link from being used by someone else. | Q-35 |
| R-004-06 | If the Invitation is `accepted`, `revoked` or expired, then the system shall show "This Invitation is no longer valid." and create no Membership. | Q-35 |
| R-004-07 | When a person who is not signed in opens an Invitation link, the system shall ask them to sign in or create an account and then show the Invitation. | Q-35 |
| R-004-08 | The system shall show the Owner the Group's open Invitations with e-mail, Role and expiry, each with "Revoke". | Q-35 |
| R-004-09 | When the Owner revokes an open Invitation, the system shall set it to `revoked`. | Q-35 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-004-01 | Ana owns "Konferenca 2025" | on 05.03.2026 at 10:00 she invites `marko.kranjc@gmail.com` as Editor | a link is shown with "Copy link"; the open Invitations list shows `marko.kranjc@gmail.com`, Editor, expires "12.03.2026 10:00"; an Audit entry is written | R-004-01, R-004-08, BR-10 |
| AC-004-02 | that Invitation is open | Marko, signed in as `marko.kranjc@gmail.com`, opens the link and accepts | "Konferenca 2025" is in his Group switcher, he is Editor, and the Invitation is no longer in the open list | R-004-04 |
| AC-004-03 | that Invitation is open | Petra, signed in as `petra.horvat@example.si`, opens the link | she sees "This Invitation is for another e-mail address." and is not a Member | R-004-05 |
| AC-004-04 | Marko accepted the Invitation | Marko opens the same link again | he sees "This Invitation is no longer valid." | R-004-06 |
| AC-004-05 | Marko is Editor of "Konferenca 2025" | Marko creates an Invitation | the response is HTTP 403 and no Invitation exists | BR-04 |
| AC-004-06 | an open Invitation for `petra.horvat@example.si` | Ana revokes it, then Petra opens the link | Petra sees "This Invitation is no longer valid."; an Audit entry for the revocation is written | R-004-09, R-004-06, BR-10 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-004-01 | Link opened 1 minute before `expiresAt` and accepted | Membership created | R-004-04 |
| EX-004-02 | Link opened at `expiresAt` | "This Invitation is no longer valid." | R-004-06 |
| EX-004-03 | Invitation e-mail `Marko.Kranjc@Gmail.com`, User e-mail `marko.kranjc@gmail.com` | Accepted (case-insensitive) | R-004-04, BR-11 |
| EX-004-04 | Invite `ana.kovac@example.si`, who is already the Owner | "This person is already a Member." | R-004-02 |
| EX-004-05 | Second Invitation for the same e-mail while the first is open | The first link no longer works; the second does | R-004-03 |
| EX-004-06 | Invalid e-mail `marko@` | "Enter a valid e-mail address."; nothing created | R-004-01 |
| EX-004-07 | Role Owner requested in the API | HTTP 400; nothing created | R-004-01 |
| EX-004-08 | A token that does not exist | "This Invitation is no longer valid." | R-004-06 |

## Out of scope

Sending the Invitation by e-mail from the product; inviting several people at once; inviting as Owner; requests to join a Group.
