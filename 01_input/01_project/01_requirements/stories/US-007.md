# US-007 Edit a Contact

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Editor, I want to change the Fields of a Contact without overwriting a colleague's change, so that the Contact stays correct and every change is traceable.

## Purpose

Contacts change (new e-mail, new company). Several Members work on the same Group, so a later save must not silently undo an earlier one (Q-24), and every change must be versioned (Q-23).

## Definitions

| Term | Meaning |
|---|---|
| Changed item | A Field whose saved value differs from the current Version. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-007-01 | When the Owner or an Editor saves changed Fields of an active Contact, the system shall store them and create one Version of kind `edited` listing each changed item with its old and new value. | Q-23, BR-05 |
| R-007-02 | The system shall validate edited Fields with the rules R-006-02 to R-006-07. | Q-10, Q-20 |
| R-007-03 | If a save contains no changed item, then the system shall show "No changes to save." and create no Version. [ASSUMPTION] not given. | — |
| R-007-04 | If the save carries a Version number that is not current, then the system shall reject it as BR-06 defines. | Q-24 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-007-01 | "Janez Novak" at Version 1 with e-mail `janez.novak@example.si` | Marko changes the e-mail to `janez@novak.si` and saves | the Contact shows `janez@novak.si`; Version 2 `edited` by Marko lists "E-mail: janez.novak@example.si → janez@novak.si" | R-007-01 |
| AC-007-02 | Ana and Marko both opened "Janez Novak" at Version 2 | Marko saves city "Maribor" (Version 3), then Ana saves job title "CEO" | Ana sees "Contact was changed by Marko Kranjc, reload"; the job title is unchanged and no Version 4 exists | R-007-04, BR-06 |
| AC-007-03 | "Janez Novak" (company empty) | Marko clears first name and last name and saves | "Enter a first name, last name or company." and the Contact is unchanged | R-007-02 |
| AC-007-04 | "Janez Novak" at Version 2 | Marko opens the form and saves without changing anything | "No changes to save." and the History still ends at Version 2 | R-007-03 |
| AC-007-05 | Petra is Viewer | she sends a change through the API | HTTP 403; the Contact is unchanged | BR-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-007-01 | Two Fields changed in one save | One Version listing both items | R-007-01 |
| EX-007-02 | Value changed only by spaces ("Janez " for "Janez") | No changed item after trimming: "No changes to save." | R-007-03, R-006-07 |
| EX-007-03 | Edit of a Contact in the recycle bin via the API | HTTP 409 "This Contact is in the recycle bin."; unchanged [ASSUMPTION] | R-007-01 |
| EX-007-04 | Edit with a Version number higher than current | Rejected as BR-06 | R-007-04 |
| EX-007-05 | Edit of a Contact of another Group | HTTP 404 | BR-02 |

## Out of scope

Editing several Contacts at once; editing Attributes (US-008) and Tags (US-009) is part of the same form but specified there; merging edits automatically.
