# US-011 Restore an earlier Version

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Editor, I want to restore an earlier Version of a Contact, so that I can undo a wrong change without retyping it.

## Purpose

Versioning is only useful if a wrong change can be taken back (Q-23); restore keeps the History complete because it is itself a new Version.

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-011-01 | When the Owner or an Editor confirms "Restore this Version" on Version n of an active Contact, the system shall make the Contact's Fields, Attributes and Tags equal to Version n and create a new Version of kind `restored` that names n and lists each changed item. | Q-18 (OPEN — needs customer), Q-23 |
| R-011-02 | The system shall keep every Version, including those after Version n, when a Version is restored. | Q-23 |
| R-011-03 | If Version n has the same content as the current Version, then the system shall show "This Version is the same as the current one." and create no Version. | Q-23 |
| R-011-04 | When a restored Version contains a Tag that no longer exists in the Group, the system shall create that Tag again. [ASSUMPTION] not given. | — |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-011-01 | "Janez Novak": Version 1 e-mail `janez.novak@example.si`, Version 2 e-mail `janez@novak.si` | Marko restores Version 1 | the e-mail is `janez.novak@example.si`; Version 3 `restored` "from Version 1" lists "E-mail: janez@novak.si → janez.novak@example.si"; Version 2 is still in the History | R-011-01, R-011-02 |
| AC-011-02 | Version 1 had Tag `udelezenec2025`, Version 2 removed it | Marko restores Version 1 | the Contact has `udelezenec2025` again | R-011-01 |
| AC-011-03 | Petra is Viewer | she restores Version 1 through the API | HTTP 403; the Contact is unchanged | BR-03 |
| AC-011-04 | Contact at Version 3 restored from Version 1 | Marko restores Version 1 again | "This Version is the same as the current one." and no Version 4 | R-011-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-011-01 | Restore with a stale current Version number | Rejected as BR-06 | BR-06 |
| EX-011-02 | Restored Version has Tag `vip`, which is on no Contact any more | `vip` exists again and is on the Contact | R-011-04 |
| EX-011-03 | Marko cancels the confirmation | Nothing changes | R-011-01 |
| EX-011-04 | Restore of a Contact in the recycle bin | HTTP 409 "This Contact is in the recycle bin."; unchanged | R-011-01 |

## Out of scope

Restoring single Fields of a Version; restoring a Contact that was permanently deleted.
