# US-010 View a Contact's History

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want to see every Version of a Contact with who changed what and when, so that I can trace every change and see what the Contact looked like before.

## Purpose

The customer requires a record of all changes of Contacts, properly versioned (Q-09 F5); traceability is a success criterion (Q-05).

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-010-01 | When a Member opens a Contact's History, the system shall list all its Versions newest first, each with number, kind, the display name of the User who made it, the time in Europe/Ljubljana as `dd.mm.yyyy HH:mm`, and each changed item with old and new value. | Q-23, Q-29 |
| R-010-02 | When a Member opens one Version, the system shall show the full content of the Contact (Fields, Attributes, Tags) as it was after that Version, read-only. | Q-23 |
| R-010-03 | The system shall never change or delete a Version while its Contact exists. | Q-23 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-010-01 | Ana created "Janez Novak" on 05.03.2026 at 09:00 UTC; Marko changed the e-mail on 01.07.2026 at 08:00 UTC | Petra (Viewer) opens the History | she sees Version 2 "edited, Marko Kranjc, 01.07.2026 10:00, E-mail: janez.novak@example.si → janez@novak.si" above Version 1 "created, Ana Kovač, 05.03.2026 10:00" | R-010-01 |
| AC-010-02 | as AC-010-01 | Petra opens Version 1 | she sees e-mail `janez.novak@example.si` and all other Fields as created, without edit controls | R-010-02 |
| AC-010-03 | User from another Group | calls `GET /api/v1/groups/<id>/contacts/<id>/versions` | HTTP 404, no data | BR-02 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-010-01 | Version made at 31.12.2026 23:30 UTC | Shown as "01.01.2027 00:30" | R-010-01 |
| EX-010-02 | Version made by a removed Member | Shown with that Member's display name | R-010-01, R-005-04 |
| EX-010-03 | API request to change or delete a Version | HTTP 405; nothing changes | R-010-03 |
| EX-010-04 | Contact with 1 Version | History shows one entry | R-010-01 |
| EX-010-05 | Version number that does not exist | HTTP 404 | R-010-02 |

## Out of scope

Restoring a Version (US-011); comparing two arbitrary Versions side by side; History of a whole Group; the Audit log screen.

## Open questions

None.
