# US-020 Choose the language

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a User, I want to switch the product between Slovenian and English, so that I can work in the language I read best.

## Purpose

The product is in Slovenian and English, Slovenian by default (Q-29).

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-020-01 | The system shall show every text of a new User in Slovenian. | Q-29 |
| R-020-02 | When a User chooses "English" or "Slovenščina" in the user menu, the system shall show every text in that language at once and keep the choice for the User's later sign-ins. | Q-29 |
| R-020-03 | The system shall show dates and numbers as `business-rules.md` (project-wide facts) defines for the chosen language. | Q-29 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-020-01 | Ana signs in for the first time | the Contact list opens | the page title reads "Kontakti" | R-020-01 |
| AC-020-02 | Ana sees Slovenian | she chooses "English" | the page title reads "Contacts" without reloading; after signing out and in again it still reads "Contacts" | R-020-02 |
| AC-020-03 | Ana uses English; a Version from 05.03.2026 10:00 | she opens the History | the time reads "05.03.2026 10:00" | R-020-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-020-01 | Language `de` via the API | HTTP 400; language unchanged | R-020-02 |
| EX-020-02 | Count 10000 in Slovenian / English | "10.000" / "10,000" | R-020-03 |

## Out of scope

Further languages; translating Contact data, Tags or Attributes; following the browser language.

## Open questions

None.
