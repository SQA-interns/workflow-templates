# US-016 Export Contacts to Excel

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want to export the Contacts I filtered, or only the ones I checked, to an Excel file, so that I can use them in other tools, for example for a mailing list.

## Purpose

The customer requires export of "označenih" Contacts to MS Excel (Q-12, Q-16): the filtered list, or optionally only Checked contacts.

## Definitions

| Term | Meaning |
|---|---|
| Export scope | The Contacts of the current list after search and filters, or the Checked contacts when the User chooses "Export checked". |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-016-01 | When a Member chooses "Export", the system shall create an `.xlsx` file of every Contact in the Export scope, one row per Contact, in the list's sort order. | Q-16, Q-28 |
| R-016-02 | When a Member has checked at least one Contact and chooses "Export checked", the system shall export only the Checked contacts. | Q-16 |
| R-016-03 | The system shall write the columns in this order: the Fields in Data-model order, then one column per Attribute key present among the exported Contacts sorted A–Z, then one column "Tags" with all Tags of the Contact sorted A–Z and joined by ", ". [ASSUMPTION] order of Attribute columns and Tags not given. | Q-28 |
| R-016-04 | The system shall write the header row in the User's language and the country as its ISO 3166-1 alpha-2 code. [ASSUMPTION] not given. | Q-28 |
| R-016-05 | If the Export scope has more than 10,000 Contacts, then the system shall show "Narrow the list to at most 10,000 Contacts to export." and create no file. [ASSUMPTION] reject rather than cut off. | Q-28 |
| R-016-06 | The system shall name the file `kontakti-<Group name>-<yyyy-mm-dd>.xlsx` with the date in Europe/Ljubljana and characters not allowed in file names replaced by `-`. [ASSUMPTION] not given. | — |
| R-016-07 | If the Export scope is empty, then the system shall disable "Export" and show "Nothing to export." | Q-28 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-016-01 | Export scope of exactly 10,000 | File with 10,000 rows | R-016-05 |
| EX-016-02 | Empty scope | "Export" disabled, "Nothing to export." | R-016-07 |
| EX-016-03 | A Field value starting with `=`, `+`, `-` or `@` (e.g. note "=1+1") | Written as text, shown as "=1+1" in Excel, not calculated | SR-07 |
| EX-016-04 | Contacts with no Attributes | No Attribute columns; "Tags" follows the Fields | R-016-03 |
| EX-016-05 | Group name "A/B: test" | File name `kontakti-A-B- test-<date>.xlsx` | R-016-06 |
| EX-016-06 | Names with diacritics "Žiga Čuk" | Written correctly (UTF-8 in `.xlsx`) | R-016-01 |
| EX-016-07 | Checked contacts include a Contact moved to the recycle bin meanwhile | That Contact is not exported | BR-09 |

## Out of scope

CSV or other formats; choosing columns; exporting History; scheduled exports; import.
