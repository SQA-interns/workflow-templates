# US-009 Tag Contacts

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Editor, I want to put free Tags such as `neObvescaj` or `udelezenec2025` on Contacts, so that I can group Contacts into categories and filter and export them later.

## Purpose

The customer expects Contacts to be marked with arbitrary Tags that serve as categories (Q-09 F4).

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-009-01 | When the Owner or an Editor saves a Contact with added or removed Tags, the system shall store them in the same save and list each as the changed item `tag:<name>` in that one Version. | Q-27, BR-05 |
| R-009-02 | When a User types in the Tag input, the system shall suggest the Group's Tags that are on at least one active Contact and contain the typed text, case-insensitively. | Q-27 |
| R-009-03 | When a Tag name is added that equals an existing Tag of the Group case-insensitively, the system shall use the existing Tag with its existing spelling. | Q-27, BR-11 |
| R-009-04 | When a Tag name is added that matches no Tag of the Group, the system shall create the Tag with the spelling entered. | Q-27 |
| R-009-05 | If a Tag name is blank after trimming, longer than 50 characters, or contains a comma, then the system shall reject the save with "A Tag must have 1 to 50 characters and no comma." and store nothing. [ASSUMPTION] comma excluded because Export joins Tags with commas (Q-28). | Q-27, Q-28 |
| R-009-06 | The system shall put one Tag on a Contact at most once. | Q-27 |

| AC-009-03 | `udelezenec2025` exists | Marko adds `Udelezenec2025` to "Maja Zupan" | "Maja Zupan" shows `udelezenec2025` (existing spelling); the Group still has one such Tag | R-009-03 |
| AC-009-04 | "Janez Novak" has `udelezenec2025` and `neObvescaj` | Marko removes `neObvescaj` and saves | Version lists "tag:neObvescaj removed" | R-009-01 |
| AC-009-05 | as AC-009-01 | Marko adds `vip, 2025` | "A Tag must have 1 to 50 characters and no comma." and nothing stored | R-009-05 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-009-01 | Tag of 50 / 51 characters | Saved / rejected | R-009-05 |
| EX-009-02 | Tag "   " | Rejected | R-009-05 |
| EX-009-03 | The same Tag added twice in one save | Stored once | R-009-06 |
| EX-009-04 | A Tag of another Group with the same name | Not suggested; a separate Tag is created in this Group | R-009-02, BR-01 |
| EX-009-05 | A Tag on no active Contact | Not suggested | R-009-02 |
| EX-009-06 | Tag with diacritics `udeležba` | Saved as `udeležba` | R-009-04 |
| EX-009-07 | Save with a stale Version number | Rejected as BR-06 | BR-06 |

## Out of scope

Tagging several Checked contacts at once; renaming, merging or colouring Tags; a Tag management screen; filtering by Tag (US-015).
