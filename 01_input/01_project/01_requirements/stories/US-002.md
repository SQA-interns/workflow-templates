# US-002 Create a Group and switch between Groups

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a User, I want to create a Group for a project or a company and switch between my Groups, so that the Contacts of each project stay apart.

## Purpose

The customer wants users to create their own contact groups, with Contacts visible only inside that Group (Q-03, Q-08). A Group needs only a name (Q-15).

## Definitions

| Term | Meaning |
|---|---|
| Group switcher | The control in the header that lists the User's Groups and shows the current one. |
| Current Group | The Group whose Contact list the User sees. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-002-01 | When a User creates a Group with a name, the system shall create the Group, make the User its Owner and make it the current Group. | Q-03, Q-07 (OPEN — needs customer) |
| R-002-02 | If the Group name is blank after trimming, or longer than 100 characters, then the system shall reject it with "Enter a name of 1 to 100 characters." and create nothing. [ASSUMPTION] 100 characters not given. | Q-15 |
| R-002-03 | The system shall list in the Group switcher, and return from `GET /api/v1/groups`, only the active Groups of which the User is a Member, sorted by name A–Z. [ASSUMPTION] sort order not given. | Q-08, Q-17 (OPEN — needs customer) |
| R-002-04 | When a User selects a Group in the Group switcher, the system shall show that Group's Contact list. | Q-17 |
| R-002-05 | When a User signs in, the system shall open the Group the User selected last, or the first Group of the switcher if that Group is no longer available. [ASSUMPTION] not given. | — |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-002-01 | Ana is signed in and has no Group | she creates the Group "Konferenca 2025" | "Konferenca 2025" is the current Group, Ana is its Owner, and its Contact list shows "No Contacts yet." with "Add a Contact" | R-002-01 |
| AC-002-02 | Ana is a Member of "Konferenca 2025" (1 Contact "Janez Novak") and "Podjetje Alfa" (1 Contact "Maja Zupan") | she selects "Podjetje Alfa" in the Group switcher | the Contact list shows "Maja Zupan" and not "Janez Novak" | R-002-04, BR-01 |
| AC-002-03 | Ana is a Member of "Konferenca 2025"; Marko is a Member only of "Podjetje Beta" | Marko calls `GET /api/v1/groups` | the response lists only "Podjetje Beta" | R-002-03 |
| AC-002-04 | Ana is signed in | she creates a Group with the name "   " | she sees "Enter a name of 1 to 100 characters." and no Group is created | R-002-02 |
| AC-002-05 | Ana last selected "Podjetje Alfa" | she signs out and signs in again | "Podjetje Alfa" is the current Group | R-002-05 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-002-01 | Name of exactly 100 characters | Group created | R-002-02 |
| EX-002-02 | Name of 101 characters | Rejected, nothing created | R-002-02 |
| EX-002-03 | Name "  Konferenca 2025  " | Group created with the name "Konferenca 2025" | R-002-02 |
| EX-002-04 | A second Group with the same name as an existing one | Group created (names need not be unique) | R-002-01 |
| EX-002-05 | Marko calls `GET /api/v1/groups/<id of Konferenca 2025>` | HTTP 404, no data | BR-02 |
| EX-002-06 | The Group selected last was moved to the recycle bin | The first Group of the switcher opens; if none, "You have no Groups yet." | R-002-05 |

## Out of scope

Group description, logo or other Group fields; sub-groups; moving or copying Contacts between Groups; renaming and deleting a Group (US-003).
