# US-019 Undo a Merge

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Editor, I want to undo a Merge, so that two different people merged by mistake become two Contacts again.

## Purpose

A Merge must be reversible (Q-26); the duplicate rule only suggests, and people make mistakes.

## Definitions

None.

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-019-01 | When the Owner or an Editor confirms "Undo merge" on a Primary contact whose latest Version is the `merged` Version, the system shall give the Primary contact the content it had before the Merge, set the Other contact to `active`, create a Version of kind `mergeUndone` on each, mark the Merge undone, and write an Audit entry. | Q-26, BR-05, BR-10 |
| R-019-02 | If the Primary contact has a Version after the `merged` Version, then the system shall reject the undo with "The Contact changed after the Merge. Restore the Versions you need instead." and change nothing. [ASSUMPTION] not given; avoids losing later changes. | Q-26 |
| R-019-03 | If the Primary contact or the Other contact is in the recycle bin, then the system shall reject the undo with "Restore the Contact from the recycle bin first." and change nothing. | Q-26 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-019-01 | "J. Novak" was merged into "Janez Novak" (Version 4 `merged`) | Marko confirms "Undo merge" | "Janez Novak" has no phone and only Tag `udelezenec2025` (Version 5 `mergeUndone`); "J. Novak" is in the Contact list again (Version 3 `mergeUndone`); an Audit entry is written | R-019-01 |
| AC-019-02 | as AC-019-01, but Ana then edited "Janez Novak" (Version 5 `edited`) | Marko chooses "Undo merge" | "The Contact changed after the Merge. Restore the Versions you need instead." and nothing changes | R-019-02 |
| AC-019-03 | Petra is Viewer | she undoes the Merge through the API | HTTP 403; nothing changes | BR-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-019-01 | Undo twice | Second attempt: HTTP 409 "This Merge was already undone." | R-019-01 |
| EX-019-02 | Primary contact in the recycle bin | "Restore the Contact from the recycle bin first." | R-019-03 |
| EX-019-03 | Marko cancels the confirmation | Nothing changes | R-019-01 |

## Out of scope

Undoing a Merge after later changes to the Primary contact; undoing only part of a Merge.
